# 直接生图提示词与局部修订

## 把视觉问题写成可观察的条件

| 常见问题 | 提示词中写出目标效果 |
| --- | --- |
| 蓝紫红铺满空腔，表面看起来在发光 | 空腔使用均匀的浅蓝灰，亮度变化微弱。强调色只用于指定部件。环境光中性，背景干净。 |
| 材质都像湿亮的塑料 | 按部件分别指定高光。金属保留细长、连续的反光。颗粒用柔和高光和间隙暗部表现堆积。薄膜保留细纤维与清晰边界。 |
| 液体或透明区被画成实心色板 | 明确透过该区域应看到哪一面或哪条边。满液腔用可见内壁和轻微透射表现，液体接到顶壁。资料表明存在自由液面时，再写出液面位置、弯月面及它和上沿的间隔。 |
| 倒角大小漂移，重复零件各画各的 | 指定复用部件的轮廓、尺寸、倒角、纹理方向和受光规律。对照图固定构图、视角、尺度和灯位，仅描述发生变化的部件。 |
| 每一层都有复杂纹理，缩小后看不出结构 | 普通面保留大面积平顺色块，细节集中于需要识别的边缘、截面或界面。关键层用局部明度差和窄接缝分开。 |

有多张参考时，在提示词开头分清每张的角色。结构图用于固定**机位视角、外轮廓、部件数量、位置、层序、各结构相对大小与厚度比例**以及前后遮挡；仿照重绘时必须显式锁定原图的视角和各部分比例不变，仅按人工绘图/C4D 特征替换对应结构的微观形态与材质。风格图只提供配色关系、纹理密度、边缘处理与灯光特征。若用户提供的是待修改原图，直接使用图像编辑，并写明要保留的区域与本次唯一要改的部分。

## 示例 · 电池式层叠结构剖面

> 根据附图直接生成一张横向科研剖面插图。附图给定剖切方向、画幅比例和部件位置。保留左右金属端盖、左端颗粒区、中部纤维隔层、右端银白薄层与它们的前后顺序。近正交视角，左右端盖使用同样的倒角、竖向拉丝和窄高光。左侧颗粒为低饱和赭黄色半哑光，颗粒表面平整，暗部留在相互遮挡处。中央层用浅米色细纤维，保持厚度平稳、交叠清楚。右端薄层用银灰和冷白的明度差显示贴合边界。腔体呈很淡的蓝灰色，内壁和邻近界面仍然可辨。整图使用一处来自左上方的中性软光，主要细节集中在薄层和接缝，背景为纯白。整幅不带文字、箭头和反应信息。避开发光粒子、光带、彩色雾和高饱和渐变。

若没有参考图，用研究描述中已确认的空间关系替换附图约束。颜色或材质具有科学含义时按用户提供的定义写入。需要文字时，把准确文本和它指向的部件逐个列出，并检查上下标、符号及大小写。

## 示例 · 局部压掉光效

> 编辑当前图，只调整左右端盖之间的腔体底色和光效。把蓝紫红背景及星点、飘带改成干净的浅蓝灰色面，保留能说明遮挡的阴影。锁定构图、端盖、颗粒区、纤维隔层和右端薄层的轮廓、位置、尺寸与表面细节。

修正后将新旧图以相同尺寸并排查看。先确认改动发挥了指定作用，再检查相邻的细纤维、透明薄层和外轮廓有无漂移。更多判断示例见 [审图指南](figure-review.md)。

## 提示片段 · 界面放大与透明介质

> 主体只标出指定界面的取景点。两根细虚线从该点引到局部窗。窗内保留界面两侧在主体中的相对位置和颜色，放大显示颗粒与基底接触时的边界。其余窗内细节采用资料可确认的部分。

> 明亮的窄反光落在容器杯口和底部收边。容器壁、内部介质和浸入介质的网络各有独立边界。外壁正面保持可透见内部，前方网络清楚，后方网络透过介质略暗。自由液面只按当前资料表现。

## 提示片段 · 凝胶、纤维隔膜、枝晶与烧杯（对齐个人 C4D 部件样本）

> **无纺布纤维隔膜 + 树枝状枝晶穿刺**：隔膜外轮廓规整为薄片，内部由大量纤细微弯的纯白至浅银灰细圆管纤维多层交织而成，孔隙透空可看穿、边缘保留自然纤维端头（不要画成实心圆孔奶酪或黑脏海绵）。枝晶呈根粗尖细、带多级不规则有机分叉的树枝状，真实穿插过纤维缝隙并呈现明确的前后遮挡关系；需要强辨识度时用清透浅蓝/银白半哑光与灰白纤维拉开对比，或对针状枝晶叠加细密银白微晶肌理。

> **水凝胶块 / 多孔凝胶骨架**：透明水凝胶块外形带柔和自然的波浪起伏与圆润软边，高透亮水润外壳保留真实表面波纹高光与边角微折射，内部清晰可见高密度缠绕的浅青蓝、淡粉红、柔淡紫粉彩哑光细圆管高分子网络。多孔凝胶骨架则保持规整方体轮廓，内部为互通海绵状三维骨架（浅紫灰底配浅天蓝菲涅尔边缘光泽），表面均匀镶嵌暖杏黄哑光小多面体颗粒。

> **透明玻璃烧杯与悬浮体系**：带倾倒嘴的标准圆柱透明玻璃烧杯，淡紫灰清透杯壁在杯口和杯底收出清晰折射轮廓边；内部盛放清透淡天蓝液体并带自然微起伏自由液面，液内清楚透见弯曲高分子细链与浅蓝/淡米黄微团聚颗粒的前后深度遮挡。
