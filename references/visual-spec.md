# 科研示意图视觉与排版规范（Visual Spec）

本规范以 *Nature*、*Science*、*Cell*、*Adv. Mater.*、*Angew. Chem.*、*IEEE* 等顶刊主流配图标准为基准，核心原则是**高信噪比、低饱和克制、严格几何秩序**。

---

## 1. 顶刊低饱和学术色板（每次限选 3–4 色 + 中性灰）

### 套系 A：Nature / 材料与电化学经典（冷暖平衡，最通用）
- 主色（阳极/主体/液相）：`#4A7FB5`（灰钢蓝）、浅填充 `#DCEAF7`
- 对比色（阴极/活性相/热区）：`#D96B43`（陶土橙）、浅填充 `#FCE6DC`
- 辅助色（隔膜/催化/保护层）：`#3B9A8C`（学术青绿）、浅填充 `#D9F0EC`
- 强调色（关键离子/产物）：`#8C6BB1`（灰紫）或 `#D4A03C`（芥末黄）
- 中性结构灰：深 `#2B303A`、中 `#7A828E`、浅 `#E5E9F0`、背景 `#FFFFFF`

### 套系 B：Cell / 生物与医学机理（柔和有机）
- 细胞质/底液：`#EEF5F9`、膜结构 `#5B8DBE`
- 靶标/受体：`#C85A53`（砖红）、配体/药物 `#E09F3E`（暖琥珀）
- 通道/信号通路：`#4D9078`（鼠尾草绿）、抑制/阻断 `#8D99AE`（冷灰）

### 套系 C：IEEE / 计算机与物理器件（极简高对比）
- 输入/基础层：`#3D5A80`（深板岩蓝）、浅填充 `#E8EEF5`
- 核心模块/计算层：`#2A9D8F`（青绿）、浅填充 `#E3F4F1`
- 关键输出/损耗：`#E76F51`（珊瑚橙）、浅填充 `#FDF0EC`
- 线框与辅助：`#1F2937`（深炭黑）、`#9CA3AF`（中灰）、`#F3F4F6`（浅底灰）

**色彩禁区**：
- 严禁使用高饱和霓虹色（如 `#00FFFF`、`#FF00FF`、`#0066FF` 配 `#FF0033` 强对比）。
- 严禁大面积纯黑或深紫红背景（除非是特定荧光显微/光致发光主题且用户明确要求）。

## 2. 字体与排版层级

- **字体栈**：`Arial, Helvetica, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- **绝对禁止**：艺术字、衬线花体、带外发光/描边/重投影的文字。
- **字号标准（以 1600px 宽基准画布计）**：
  - 子图编号（`a`, `b`, `c`）：`24px–28px`，`font-weight: 700`，颜色 `#111827`，位于每个子图左上角严格对齐。
  - 模块主标题（如 `Liquid`, `Solid-state`, `Encoder`）：`18px–22px`，`font-weight: 700`，颜色 `#1F2937`。
  - 部件标注与化学式（如 `Zn²⁺`, `SO₄²⁻`, `Zn anode`）：`14px–16px`，`font-weight: 600`，上下标字号为正文的 `70%–75%`。
  - 辅助注释与图例说明：`12px–14px`，`font-weight: 400–500`，颜色 `#4B5563`。
- **文字底衬原则**：文字若不得不落在有纹理的图块上方，必须增加半透明纯白圆角衬底 `rgba(255, 255, 255, 0.85)`，确保绝对清晰可读。

---

## 3. 线条、箭头与放大框规范

- **边框与容器线宽**：`1.5px–2px`，圆角统一（`rx="6"` 或 `rx="8"`），同级模块边框颜色与粗细完全一致。
- **流动/过程箭头**：
  - 主流程箭头：实线 `2px`，实心简洁三角箭头，禁止带渐变发光尾焰。
  - 扩散/离子迁移/辅助路径：虚线 `stroke-dasharray="5,4"`，线宽 `1.5px`。
- **多尺度放大框（顶刊人工感最强锚点）**：
  - 源区域：小矩形框（`stroke: #3B5B8C`, `stroke-width: 1.5`, `fill: none`）。
  - 引线：两条笔直细实线精确连接源方框的上下角与右侧放大图的上下角，严禁歪斜或悬空。
  - 放大图容器：浅色干净背景 + 同色系 `1.5px–2px` 边框。

---

## 4. 经典多尺度布局范式

1. **上下对照组 + 左到右多尺度（如 `a` vs `b` 电池/催化对比）**：
   - 左侧（42% 宽）：宏观装置剖面（`a` 和 `b` 复用相同外壳/不变电极）；
   - 中间（28% 宽）：界面局部放大图（用精确引线拉出）；
   - 右侧（26% 宽）：极简 2D 机理/成分抽象图（纯扁平矢量）。
2. **左到右三段式机理演化**：
   - 三个等宽圆角容器横向排列，用统一灰色粗箭头连接，底部配统一图例条（Legend Bar）。
3. **模块化分层架构图（CS / 工程）**：
   - 严格 12 列网格对齐，外框用浅灰虚线分组，内部子模块等高对齐，连线采用正交折线（90° 拐角）而非随意弯曲的曲线。
