# 个人 C4D 成图风格参考

本参考从用户提供的两批成图提炼。用户要贴近本人作品风格时，选最相近的题材做视觉参照。交付沿用直接生图或图像编辑。当前任务的配色、底色、视角和标注要求优先。

## 共同特征

- **纯粹 3D 建模渲染质感（严禁绘本/插画色调）。** 所有三维部件均为纯粹的 3D 软件物理渲染模型：轮廓靠真实 3D 光影与前后遮挡确立，**无 2D 轮廓描边线、无水彩/绘本笔触感、无发灰发粉的插画滤镜**。色彩保持纯净明快的高明度本色，避免被莫兰迪插画色调拉闷拉平。
- **用基本形体交代装配。** 板、筒、框、滚轮和圆片轮廓明确，平面平整，圆角收得小。相同零件在可比视角下保持同款轮廓、比例和表面处理。接触、贴合和遮挡清楚。
- **材质通过不同的反光来区分。** 金属可以亮。高光沿端盖曲面、圆角和棱边连续过渡。平面设备壳、传送带和管件以平顺色面为主。纤维交叠、颗粒堆积或透明介质的纹理集中在有结构信息的地方。
- **中性环境与局部彩色并存。** 灰、暖灰或白在各样本里都出现。蓝、黄、粉、深靛和红也有鲜明实例。比饱和度更重要的是颜色的分布。同类部件色彩一致，明显的颜色落在要区分的材料、功能部件或路径上。
- **注释和装饰服从图意。** 单件渲染可以只有主体。装置图里，清楚的黑线和标签负责说明连接，局部半透明彩色光束用于画光路。综合机制图可同框使用三维材质、平面机制、流程箭头和图例。

## 按题材取用

| 样本 | 可迁移的处理 |
| --- | --- |
| 电芯剖面 | 正视或轻斜视，端盖高光稳定。用清透淡蓝的大面、暖黄色颗粒和窄纤维层区分内部结构。依据当前资料确定介质状态与层序。 |
| 卷对卷设备 | 同类滚轮统一圆径、端面环色与轴向，传送带用连续薄带交代路径。机壳以简化平面和清楚开口表现层次。 |
| 球棍微结构 | 控制球径和杆粗，保持孔道与颗粒遮挡清楚。键连关系和元素颜色以原始资料及用户约定为准。具体色泽参照下节。 |
| 研钵和研杵 | 基本轮廓清楚，主体可以使用深而饱和的同色材质。高光顺着凹面与曲面变化，样品以明度对比突出。 |
| 光路装置 | 用简单的三维器件建立空间关系，黑线表示连接，半透明彩色光束只沿实际光路。区分器件端点和光束穿过的位置。 |
| 多尺度机制总览 | 用白底承载多个小画面。器件、材料或应用可以有立体质感，箭头、线和图例用更平面的表达。重复出现的对象保持同款，别把参考中的配色误当通用的离子图例。 |

## 第二批样本带来的补充

| 题材 | 可迁移的处理 |
| --- | --- |
| 装置、材料块、器件和界面 | 主体负责交代装配与层序。材料块或局部窗口承担孔隙、颗粒、粗糙接触界面等高密度细节。放大前后复用至少一个易辨认的边界、颜色或颗粒形态，便于从窗口回到主体。部件名称和界面标题逐一核对。 |
| 外电路与工况说明 | 保留连续的导线轮廓和清楚的开关、负载接点。符号化的灯泡亮度、光束、热箭头或火焰分别落在有明确含义的部位。材料剖面保持清楚。不同窗口可分别解释界面结构、分子结构或工况。 |
| 盛有介质的透明容器 | 用杯口、壁厚与底座的局部高光显示容器。介质的颜色和内部网络的前后遮挡独立控制。有自由液面的题材才画清液面和顶部空间。 |
| 有重复单元的曲面与层叠体 | 同类表面单元保持可识别的轮廓和尺寸，沿球面转向且附着在外壁。并排对照的薄片用一致的观察方向、共同层序与比例建立可比性。只改资料确认的变量。规整薄片和粗糙网络用尺度及边缘形态区分。 |

用样本提取画面特征时，分别确认主体材质、环境底色和最终排版。透明图的显示衬底、截屏边缘、渲染噪点和单张图的留白属于具体样本条件。把可观察的要点写进提示词，例如“灰银端盖等宽，窄高光贴随上沿圆角，蓝色区域用透射可见内边界”，再用同一组要点验图。

## 球棍材质样图

这组球棍样图最核心的共同特征是**正面近相机方向主光（头灯式布光）+ 纯净无灰的高明度本色**：
- **光向与明暗**：主光几乎正对镜头（略偏球心左下），使球面约 80% 面积呈现明亮通透的本色，暗部沿球体轮廓四周均匀收拢成一圈窄暗边（而非侧光造成的半明半暗月牙阴影）。前排原子与键杆**不向后排投射黑色硬阴影**，仅在键杆插入球体的接缝处保留极窄接触暗圈；球面除纯白点高光外无杂乱环境反射。
- **高纯度色相**：底色纯净不掺灰调（例如正红球中心亮区红通道达 244–247，绿、蓝通道近乎为 0），饱和蓝、黄绿与浅青均保留鲜明本色；白球呈乳白或浅粉白，灰球为干净中性灰。先保证球身中间调亮度与色相纯度、缩回侵入中段的暗区，再校准高光大小。
- **两档光泽按样本区分**：
  - **半光针尖档（参考图 1/2）**：高光极细小（针尖或微小双点），表面偏半光漫反射；键杆为中性灰白或中灰圆柱（高光带较弱）。
  - **亮面釉质档（参考图 3/4）**：高光呈清晰锐利的纯白圆斑（接近一成球径），边缘收紧无外扩光晕，球缘收暗利落，质感接近上釉树脂/硬塑料。
- **键杆与底色**：键杆为有粗度的圆柱，沿杆身有明暗过渡（亮面档带一条轴向细亮带）。全灰白/中灰杆用于统一中性编码；双色/同色编码时，同色重原子键随球体同色、异核重原子键在杆中点双色分割、连氢白球的键保持浅白。样图周边为透明像素，比对时把参考和候选放在同一浅底或目标底色上对照。色泽样图里的分子结构和元素配色只在任务确认时使用。

> 一句话渲染基准：**用正面近相机方向主光照亮纯净无灰的高明度本色球面（约 80% 宽亮面），沿轮廓四周收出均匀窄暗边，叠一颗贴近球心的锐利纯白高光，无原子间投射硬影与环境杂色反射，按需选用半光针尖档或亮面釉质档。**
