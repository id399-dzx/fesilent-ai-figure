# C4D 科研成品视觉风格基准（Fesilent C4D Style DNA）

## 2. 六大不可违背的 C4D 风格基因

1. **高调清透光照（High-Key Soft Studio Lighting）**
   - 整图偏亮、干净、通透，阴影极浅且柔和（Soft Ambient Occlusion）。
   - **严禁**：暗黑背景、戏剧化强明暗对比、电影感体积光、丁达尔效应、暖黄/青橙电影滤镜。
2. **粉彩哑光与清透半透明材质（Pastel Matte & Clean Translucent）**
   - 固体部件优先使用**低对比粉彩哑光塑料/粘土/微缎面材质**（灰蓝 `#8AA7D6`、樱花粉 `#DFB6C9`、卡其米 `#B39B73`、浅银灰 `#D0D5DC`、明亮暖黄 `#FAD44B`、暗砖红 `#9E3E3E`）。
   - 金属部件仅保留**干净、克制的线性渐变高光**，不要重做旧、重划痕、重工业噪点或油腻镜面反射。
   - 液相、光束、细胞膜使用**干净清透的浅色半透明填充**（淡天蓝、淡粉红、淡青绿），绝不加发光粒子、星云、飘带或光晕。
3. **规整几何体与微倒角（Clean Geometric Primitives）**
   - 仪器、辊轴、电极、壳体由干净的基础几何体（圆柱、方框、球棍、平板）组成，边缘略带圆角倒角，形体干脆利落。
4. **全图无限景深（Infinite Depth of Field）**
   - 所有前后景元素均保持**绝对清晰锐利**，严禁使用相机浅景深虚化（Bokeh / Depth of Field Blur）。
5. **干净背景策略（二选一）**
   - **默认（单部件、剖面、工艺、晶格、综合机理图）**：绝对纯白 `#FFFFFF`，无地面投影。
   - **俯视实验台/光路平台（仅物理光学台类题材）**：允许使用极浅中性灰 `#ECEEEF` 柔光背景 + 极柔和底部接触阴影。
6. **C4D + 矢量混排的朴素工程标注**
   - 连线/电路使用**纯黑细折线（`1.5px–2px`）**，流程衔接可用**极浅天蓝渐变箭头（`#9EC5FF` → `#DCEBFF`）**。
   - 文字使用朴素纯黑无衬线体（Arial / Helvetica），不加浮夸卡片外框、不加文字阴影或外发光。
   - 3D 渲染件与极简 2D 矢量图（波形、电路符号、膜通道、神经网络）自然并排，保留清晰的“人工建模 + 后期排版”分层感。
