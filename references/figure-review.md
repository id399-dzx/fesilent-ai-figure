# 科研图逐图审查和返修

根据实际任务写几项验收条件。措辞应能对照成图判断，例如“两列只有右端界面层不同”“缩至单栏时仍可区分银色基底与浅色薄层”。简单图心里核对即可。需要多轮返修时，用一两句记下**区域 → 可见现象与可能误读 → 本轮改动与保留项 → 修后证据**。

| 区域与可见现象 | 判定及改法 | 修后核对 |
| --- | --- | --- |
| 对照图两边都有手和器件，缩小后只读到两个局部放大 | 如果任务要说明仿生对应，先核对两边是否有可比较的触发动作、处理节点或输出。用同类触碰姿势、相应位置和明确的面板分区表现已知关系。 | 请审图者先只看成图，指出哪两部分互相对应、事件从哪里开始。再对照资料核实界面和信号。 |
| 草图中的大脑图形换成通用芯片，仿生类比消失 | 把“图标表达的功能”和“保留哪种形象”分别确认。资料只说明它表示信号处理时，可保留脑形并明确标注功能。脑与芯片组合适用于已确定的生物与电子处理类比。 | 核对功能标签和形象，避免让读者把象征性的图形读成实物、实际连接或信号测量。 |
| 各材料层都清楚，但等间隔分离使整体像一叠样片 | 先确认是在展示装配、工作状态还是爆炸分层。装配或工作状态重点表现层间贴合、统一曲率、薄膜对下一层的遮挡和透射。 | 让审图者先判断这是一个复合器件还是分开的材料；放大核对层序和每条标注的落点。 |
| 电池两腔的蓝灰面像实心板 | 若资料确认是满液腔，让后壁或已知内边缘透出来，液体连续贴到上壁。只有资料确认存在气液界面时，才画出明确液面或弯月面。 | 先看腔体是否仍像一整块蓝色玻璃板或实体，再核对层序和界面位置。观察端盖、颗粒区、纤维隔层及薄层是否仍一致。 |
| 对照组同一个端盖变宽，倒角和拉丝方向也变了 | 先确认两组使用相同零件且视角、光照可比。修复轮廓和纹理漂移，保留唯一的实验变量。若画面只换了观察角度，应比较可对应的结构特征。 | 并排核对轮廓、材质方向、尺度以及题目约定的差异。 |
| 主体外侧有饱和光晕，缩小后掩盖边界 | 去掉遮住边界且没有解释功能的光晕。荧光、假彩色或热图中的亮色照图例和资料保留。 | 核对实际尺寸下的颜色含义、边界与图例，确认关键色阶可辨。 |
| 某个引线终点落到相邻层，两个层看起来像一个 | 有科学误读风险。优先修正落点与层界，保住标注全文和相邻部件。 | 重新从引线起点读到落点，核对标签、相邻层和现有连线。 |
| 放大窗的标题、取景处和内部结构指向不同界面 | 从主体标注和放大框回查目标边界，再检查窗口里两侧材料的相对位置与颜色。源图里这些信息相冲突时，以可核实的项目资料为准。 | 按两条引线从主体走到窗口，核对主图部件名、界面名称和放大内容三者相符。 |
| 器件有高光和火焰符号，缩小后看不清接点或工况 | 弱化遮住接点的光效，保留有意义的工况提示。标明示意工况的含义，性能结论使用有来源的文字或数据。 | 分别看静态拓扑和示意效果。检查开关、负载和引线端点都读得清，图例所指能在图中找到。 |
| 3D 模型偏绘本/2.5D 插画色调、带伪描边线或色彩发粉发灰 | 提示词混入插画/粉彩诱导词，或借鉴构图参考图时被其插画渲染风格污染。判定为质感不合格：剥离插画风格参考与绘本词汇，改回纯粹 3D C4D 物理渲染表述（纯净本色、真实曲面光影、锐利高光、零描边线）重新生成。 | 放大检视球体、碳管、容器与设备的边缘和受光面，确认完全无描边线、无画笔/水彩质感，色彩纯度与 3D 体积感与用户 C4D 原件一致。 |
| 仿照重绘后视角变斜、各层厚薄或部件大小漂移 | 重绘时脱离原图机位或擅自按新风格重排比例。返修时显式锁定原图相机视角、外框边界与各结构的相对尺寸/厚度比例，仅替换指定结构的材质与人工建模微观特征。 | 与原图同尺度并排叠加比对，确认相机视角、总宽高比、每层厚度占比及放大窗位置大小与原图一致。 |
| 局部编辑修好目标区，但空白区或邻近部件长出幻觉杂物 | 图像编辑缺少区域隔离导致“改 A 坏 B”。停止继续整图滚雪球重抽，直接保留旧版干净底图，将新版修好的目标区域做局部精确合成，或缩小蒙版范围重修。 | 全画幅同尺度对照，确认目标区改善且所有空白区、边界、已有文字和保留部件零污染。 |
| 复杂分子化学键连反复画错（如含氟盐、配合物） | 概率图像模型对精确化学价态存在上限。连续 2 轮提示/编辑仍错连时立即止损，改由化学绘图/三维坐标精确渲染后无痕嵌入，避免耗尽配额。 | 单独核对每个原子的配位数、键级、对称性与颜色图例，与样式验收分开通过。 |
| 透明容器像乳白实心罩，或透明输出出现彩边与空洞 | 容器边缘和介质分别调整。把高光限制在轮廓、杯口或底座附近，并检查内部网络能否透见。默认最终输出必须为透明背景 PNG（RGBA），提取 Alpha 时对玻璃/介质做去白底半透明还原而非硬阈值挖洞。 | 透明 PNG 在纯白、浅色和深色底色下同时查看，确认外轮廓无白边/彩边，薄纤维、透明壁与主体内部均完整无空洞。 |

**先修会改变读法的问题。** 错误的部件、层序、分组、数据、符号、连接和材料状态，属于影响交付的内容错误。高光太亮、颜色略闷或细节过密通常是呈现问题。如果确实遮住了界面，按读者的误读风险提高优先级。配色有明确任务时按其本身的可读性检查。

**按出图时已有的资料评估可预防问题。** 用户后来给的成图可以解释预期的读法，也可能补充了早先没有的受体类型、检测变量或功能层。先回看原草图、已确认答复和使用过的来源。应提前确认的是整图要表达的关系，新增的项目细节应依据补充资料再画。

**按问题范围选择动作。** 当前图已满足任务就保留。位置明确的单个问题，基于当前最好的一版做局部编辑。整体层序、机位或多处重复件一起漂移时，带上原约束和结构参考重生成。图面在目标显示尺寸审核读序与文字，放大审核修改处、相邻边界和明示保留项。用相同尺寸和底色对比前后两版。若改动牵连应保留的内容，回到更符合资料的一版，缩小编辑范围或重新生成。反复出现同一种漂移时，保留最可靠的版本供预览。如仍有科学内容错误，标为草稿并指出问题位置。

## 指定参考时的素材复用与质感校准

- **复用原件。** 先找未叠注释的原件。只有带批注的版本时，可提取原件并限定去批注或改色的区域。对白底、透明边、轮廓、反光和内部细节做前后对照。若只换液色，检查瓶盖、玻璃厚度、液面和反光都与源图一致。保持原液色时避免顺手调色。
- **判明结构样本的角色。** 从参考区域指认要采用的结构特征和主图中的落点。若它用于替换，结构应出现在对应部件内，验收时看主图本身是否能读出新结构。若它是独立放大窗，验收取景点、放大内容和引线。两项都明确要求时可同时做。
- **先比代表样件。** 把参考与候选的同类部件放到相同底色、相近显示尺度，透明图先核对实际 Alpha。选最容易暴露差异的一个部件先出样并修正。球棍可选亮色球、白球及连接杆，先比较球身亮面与暗边，再比较高光形状、颜色和杆身明暗。差异肉眼已明确时直接调整，必要时取同色、同相对位置的小区域比较中间调，避开高光和抗锯齿边缘。像素数值只用于本次对照。
- **把风格验收与事实验收分开。** 更亮的版本仍需核实原子、键级、离子连接、图例和元素颜色。通过代表件后再批量应用该材质并放入整图，在交付尺寸复查。首个样件已有显著差异时先修样件，避免重做整套图。风格参照未达到且影响用户要求时，在交付中说明具体差距。
