# 反 AI 味鉴伪与验收清单（Anti-AI Checklist）

每次生成科研示意图后，必须以**严苛审稿人**的视角逐条排查以下 6 大高频 AI 破绽。只要命中任意一条，视为验收不通过，必须定点返工。

---

## 1. 装饰性熵增排查（头号 AI 味来源）
- [ ] **发光特效清零**：画面中是否存在毫无物理意义的发光圆点（glowing dots）、霓虹光晕、发光尾焰箭头、星尘粒子或半透明科幻飘带？
- [ ] **渐变克制**：腔体或背景是否出现了高饱和的红蓝/青橙/蓝紫“电影海报渐变”？学术腔体应为干净浅色或单色微渐变。
- [ ] **无意义复杂纹理**：是否存在只是为了“看起来很科技”而画的乱序蛛网、模糊光斑（latent blobs）或杂乱无章的装饰线条？

## 2. 背景与图层分离排查
- [ ] **绝对纯白底**：画布背景和四周边缘是否为纯白 `#FFFFFF`（不能是带灰底、暗角或泛黄的伪白底）？
- [ ] **清晰图层边界**：3D/材质素材与 2D 矢量边框、标注文字之间是否有清晰的“工程拼接感”，而不是全图糊在同一种油腻像素渲染里？

## 3. 实例一致性排查（是否真正复用了素材）
- [ ] **跨子图一致**：在对照组（如 `a` vs `b`）中，未发生变化的组件（如同一端盖、同一外壳、同一电极、同一框架）是否做到 100% 几何与视觉一致？
- [ ] **同图符号一致**：代表同一概念的离子、分子、受体、模块在图中出现多次时，大小、形状、颜色是否完全统一？

## 4. 物理与逻辑拓扑排查
- [ ] **结构合理**：电路/管道/连接线是否真实接入端点（绝不出现灯泡悬空、导线穿玻璃、箭头在金属内部乱转）？
- [ ] **接触面与边界**：不同材料层之间边界清晰，无莫名其妙的粘连融化（如颗粒融成一坨）或无端悬浮。
- [ ] **引线精确对齐**：局部放大框的引线是否精准连接源方框顶点与目标放大框顶点？

## 5. 文字、公式与标注规范排查
- [ ] **100% 矢量清晰**：图中所有文字、数字、化学式、箭头是否全部由 HTML/SVG 矢量层生成，绝对禁止出现 AI 像素生成的微糊文字？
- [ ] **无冗余标注**：同一个部件是否在图内和图外被重复标注了两次（如方块里写了 `Metal Anode (M)`，下面又写 `Metal Anode (Metal M)`)？
- [ ] **上下标与可读性**：所有离子电荷（如 `Zn²⁺`, `SO₄²⁻`）和化学下标是否正确排版？文字是否清晰可读、没有直接压在杂乱深色纹理上且没有被线条穿过？

## 6. 色彩语义纯净度排查
- [ ] **一色一义**：能否用一句话说出图中每种颜色对应的科学含义？如果某种颜色纯粹是为了“好看”，立刻改为中性灰。
